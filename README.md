# The Meeting That Should Have Been One Line

A make.fun bounty entry for [The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

The program writes a single line to `/output/entry.txt`:

> This meeting could have been an email, and the email could have been a shrug.

Run it with:

```sh
python3 main.py
```

The output directory can be overridden with the `OUTPUT_DIR` environment variable.
